# Story Bible — Case 001

## 실제 진실

2026년 8월 11일 저녁, 마케팅 담당 서연은 다음 날 공개할 홍보 캡처에 오래된 화면이 들어간 사실을 발견했다. 정식 담당자들은 이미 퇴근 중이었고, 서연은 허가를 구하지 않은 채 편의점에 들렀다가 20:18 자신의 파란 임시 카드로 사무실에 다시 들어왔다. 20:20 붉은 프로토타입 USB를 개발 허브에서 뽑아 홍보용 PC에 연결했다. 보안 경고가 뜨자 감사 로그가 남았다는 사실에 당황했고, USB를 회의실 보관함 2B에 잠시 숨겼다. 메모와 보관함 태그를 정리하는 과정에서 태그는 테이블 아래, 열쇠는 휴게실 컵 수거함 뒤에 떨어졌다. 20:27 퇴실한 서연은 징계를 피하려고 재입실과 USB 접촉을 부정했다.

USB를 영구적으로 훔칠 의도는 없었지만, “누가 원래 자리에서 옮겼는가?”의 답은 서연이다.

## 인물 이동 경로

- 민수: 개발 좌석 → 출입구. 회의실·휴게실에는 가지 않음.
- 지연: 회의실 → 출입구. 20:14 이후 재입실하지 않음.
- 준호: 복도 → 약국 → 출입구 보안 데스크. USB가 옮겨진 실내에는 없음.
- 서연: 출입구 → 편의점 → 사무실 허브 → 회의실 2B → 휴게실 앞 → 출입구.

## Stage reveal

1. 빈 슬롯을 통해 “물건이 실제로 옮겨졌다”는 사건을 확정한다.
2. 2B 표식과 방을 넘는 시간 흔적으로 사건의 범위를 확장한다.
3. 네 사람 모두 거짓말할 이유가 있음을 보여 “거짓말 = 범인” 공식을 깨뜨린다.
4. 서연의 재입실, 회의실 방문, USB 접촉을 순차적으로 인정시킨다.
5. 객관적 타임라인으로 세 개의 red herring을 분리하고 서연을 지목한다.

## 결말과 확장

서연은 USB를 돌려놓고 징계 절차에 협조한다. 마지막 화면에는 USB의 감사 로그에서 알 수 없는 두 번째 장치 ID가 짧게 보인다. 이는 데모의 정답을 흐리지 않으면서 후속 사건의 연결 고리로만 남긴다.
