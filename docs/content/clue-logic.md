## 최소 논리 경로

1. 빈 슬롯으로 분실을 확정한다.
2. 메모 + 태그로 회의실 2B를 특정한다.
3. 카드 + 영수증으로 서연의 재입실을 확정한다.
4. 태그 + 열쇠로 2B를 열고 USB를 찾는다.
5. 카드 + USB 접근 시각, 그리고 “만지지 않았다”는 진술을 결합한다.

커피컵·붉은 책·약 포장지는 다른 거짓말을 설명하지만 단독 또는 조합으로 서연을 확정할 수 없다. 핵심 단서 하나를 늦게 찾더라도 각 방의 hotspot은 이전 Stage 이후 계속 활성화되어 소프트락이 발생하지 않는다.
