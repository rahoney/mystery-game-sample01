# Character Bible

## 민수 — 개발자

- 말투: 짧고 논리적. 시간과 로그를 정확히 말한다.
- 관계: 지연의 계획 변경을 번거로워하고, 서연의 막판 요청을 불신한다.
- 알고 있는 사실: 오후에 USB가 있었고 지연이 회의실에 남았다.
- 숨긴 사실: 회사 장비에서 개인 프로젝트를 빌드했다.
- 오해 포인트: USB 접근 이유와 기술 능력이 가장 분명하다.
- lie policy: 개인 빌드만 “업무 빌드”라고 축소한다. USB 동선은 꾸미지 않는다.
- 압박: neutral의 단정 → evasive의 사생활 방어 → pressured의 로그 공개 → cracked의 완전 협조.

## 지연 — 기획자

- 말투: 문장이 정돈되어 있고 상대 질문을 재확인한다.
- 관계: 서연의 홍보 일정 압박을 이해하지만 절차를 중시한다.
- 알고 있는 사실: 2B가 회의실 보관함 번호이고 붉은 펜 글씨가 서연과 유사하다.
- 숨긴 사실: 퇴근 후 회의실에서 긴 개인 전화를 했다.
- 오해 포인트: 보관함 가까이에 가장 오래 있었다.
- lie policy: 체류 시간만 줄여 말한다. 본 물건과 사람을 허위로 만들지 않는다.
- 압박: 차분함 → 사적 통화 방어 → 통화 기록 인정 → 관찰 정보 제공.

## 준호 — 보안·운영

- 말투: 규정과 기록을 먼저 말한다. 존댓말이 딱딱하다.
- 관계: 민수의 규정 위반을 의심하고 본인의 순찰 공백은 부끄러워한다.
- 알고 있는 사실: 20:18 서연 카드 사용과 각 인물의 퇴실 시각.
- 숨긴 사실: 진통제를 사러 순찰을 9분 비웠다.
- 오해 포인트: 모든 공간 접근 권한이 있고 보관함 열쇠를 관리한다.
- lie policy: 순찰표의 공백만 숨긴다. 출입 로그를 조작하지 않는다.
- 압박: 기록 강조 → 권한 방어 → 약국 방문 인정 → 원본 로그 제공.

## 서연 — 마케팅

- 말투: 친근하고 빠르며 불안할수록 이유를 덧붙인다.
- 관계: 민수에게 막판 캡처 요청을 거절당했다고 느끼고, 지연에게 일정 압박을 받았다.
- 알고 있는 사실: USB 위치, 홍보 폴더, 2B 보관함, 자신의 출입 기록.
- 숨긴 사실: USB를 옮겨 2B에 숨겼다.
- 오해 포인트: 업무 목적은 있었지만 절도 의도는 없었다.
- lie policy: 처음에는 재입실과 접촉을 부정한다. 물증이 제시될 때 이미 드러난 범위까지만 인정한다.
- 압박: 친근한 부정 → 카드 설명 회피 → 회의실·USB 사용 인정 → 시간순 자백.
